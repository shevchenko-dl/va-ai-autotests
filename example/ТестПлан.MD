# ТестПлан: va-poc A/B

> Единый вход для вариантов A (skill без MCP) и B (агент с MCP VA). Конфигурация: 1С:ERP (демо-база «<демо-база 1С:ERP>»).

## Тест 01: Заказ_поставщику_Приобретение_ТиУ

**Дано:**
- Организация «Тестовая организация, ПАО» существует в базе (создавать НЕ нужно).
- Партнёр-поставщик «_Основной поставщик, ЗАО» существует (создавать НЕ нужно); соглашение в заказе не заполняется.
- Склад «_Основной склад» существует (создавать НЕ нужно).
- Номенклатура «_Абразивная крошка», «_Бумага наждачная», «_Лист стальной» существует (создавать НЕ нужно).

**Когда:**
- Создаём документ «Заказ поставщику»: организация «Тестовая организация, ПАО», партнёр «_Основной поставщик, ЗАО», склад «_Основной склад».
- Добавляем 3 строки товаров: «_Абразивная крошка» — 1 шт. по 100; «_Бумага наждачная» — 2 шт. по 200; «_Лист стальной» — 3 шт. по 300.
- Устанавливаем статус «Подтвержден», проводим и закрываем заказ.
- Из списка «Заказы поставщикам» создаём на основании заказа документ «Приобретение товаров и услуг», проводим и закрываем его.

**Тогда:**
- Заказ поставщику проведён без ошибок (форма закрылась, сообщений об ошибках нет).
- В документе «Приобретение товаров и услуг» ровно 3 строки товаров.
- Номенклатура, количество и цена каждой строки приобретения совпадают со строками заказа.
- Приобретение товаров и услуг проведено без ошибок.
- Сценарий можно запускать повторно: документы, созданные предыдущими запусками, не мешают (идемпотентность).
